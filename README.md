# EX4 - API REST de Clientes
Fatec Americana - Prof. José William Pinto Gomes

API em Node.js (Express) com SQLite que expõe o cadastro de clientes do EX3.
Retorna JSON, usa autenticação JWT e tem CORS habilitado.

## Como executar
1. `npm install`
2. `npm start`
3. A API sobe em http://localhost:3000


## Uso de IA
Durante o desenvolvimento desta atividade, utilizei ferramentas de Inteligência Artificial como apoio para compreender a estrutura e a implementação das funcionalidades. A IA foi utilizada como uma base de consulta e orientação, ajudando a esclarecer dúvidas, apresentar exemplos de código e explicar passo a passo como cada recurso deveria funcionar.

Com esse auxílio, consegui estudar e desenvolver os seguintes pontos:

Estrutura das rotas REST: compreensão da organização dos endpoints, dos métodos HTTP e dos códigos de status utilizados nas respostas da API.

Autenticação com JWT: entendimento da geração e validação de tokens, além da utilização de middlewares para proteger as rotas.

Tratamento de erros e CORS: implementação de um formato padronizado para respostas de erro e configuração do CORS para controlar as permissões de comunicação entre aplicações.

Documentação dos endpoints: organização de um modelo de documentação para descrever as rotas, seus parâmetros, métodos, respostas e possíveis erros.

Além da IA, utilizei materiais de apoio e exemplos para complementar o aprendizado. Os códigos e as estruturas apresentados foram analisados, testados e adaptados conforme as necessidades da atividade.

A ferramenta foi importante durante o processo, não apenas para auxiliar na construção do código, mas principalmente para entender a lógica por trás de cada implementação. Ao longo da atividade, procurei compreender o funcionamento dos recursos utilizados para conseguir explicar as decisões e a estrutura desenvolvida.
